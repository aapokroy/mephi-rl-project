# Навигация при непредсказуемом ветре

Итоговый проект по обучению с подкреплением. Артём Покрой.

[Ноутбук с кодом, графиками и выводами](rl_project_Pokroy.ipynb).

Собственная среда Gymnasium: агент обходит обрыв на поле 9×9, ветер может сдвинуть его вниз. Сравниваются Q-learning с постоянным ветром и со случайной силой ветра при обучении, безопасный маршрут и случайная политика.

В проверенных условиях рандомизация не дала преимущества: оба обученных варианта достигли цели во всех тестовых эпизодах. Ограничения эксперимента разобраны в ноутбуке.

Для запуска: Python 3.11, зависимости из `requirements.txt` и Jupyter. Внешние данные не нужны. В ноутбуке сохранены результаты; в `artifacts` лежат таблицы оценки, графики и обученные Q-таблицы.
